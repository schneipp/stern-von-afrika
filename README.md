# Stern von Afrika

Eine Web-Version des Brettspielklassikers „Afrikan tähti“ / „Der Stern von Afrika“ für 2–5 Spieler, gegen Freunde am selben Gerät oder gegen den Computer.

Wer findet den Stern von Afrika und bringt ihn zuerst nach Kairo oder Tanger? Unterwegs warten Rubine, Smaragde, Topase, Hufeisen und Räuber.

## Spielen

Keine Installation und kein Build nötig. `stern-von-afrika-v2.html` im Browser öffnen; die Datei `stern-von-afrika-relief.jpg` muss im selben Ordner liegen. Ein laufendes Spiel wird im Browser gespeichert.

## Regeln in Kürze

- Alle starten mit £ 300 in Kairo oder Tanger.
- Würfeln und genau so weit ziehen; Städte mit verdecktem Plättchen beenden den Zug.
- Landwege sind frei, Seewege kosten £ 100 pro Zug, Flüge £ 300.
- Plättchen für £ 100 aufdecken oder im nächsten Zug mit einer 4–6 kostenlos.
- Wer den Stern heimbringt, gewinnt. Ist der Stern gefunden, gewinnt auch, wer zuerst mit einem Hufeisen ankommt.

Städte, Wege und Plättchenverteilung sind an das Original angelehnt, aber frei gestaltet.
